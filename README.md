# 🎮 GameHub

Modern game discovery platform built with HTML, CSS and JavaScript.

---

## 🌐 Live Demo
https://solteroo.github.io/Gamehub/

---

## 📌 About Project

GameHub is a frontend game catalog system where users can browse, search, and filter games with a clean UI experience.

It is designed as a prototype for a future full-stack gaming platform.

---

## ✨ Features

🎮 Game catalog system  
🔎 Live search filtering  
🗂 Category filtering system  
❤️ Favorites (localStorage)  
📱 Responsive design (mobile friendly)  
⚡ Fast GitHub Pages deployment  

---

## 🧠 Tech Stack

HTML5  
CSS3  
JavaScript (Vanilla)  
GitHub Pages

open index.html  

---

## 📦 Features Explanation

Game Listing:
Displays all games in clean card layout.

Search System:
Instant filtering based on user input.

Category Filter:
Filters games dynamically by type.

Favorites:
Stores favorite games in browser localStorage.
