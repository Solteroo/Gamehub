📌 About the Project
GameHub is a simple game discovery interface where users can browse, search, and filter games by category.
It is designed as a clean UI prototype for a future full-stack gaming platform.
The goal of this project is to simulate a modern game library experience with fast performance and minimal design.
✨ Features
🎮 Game listing interface
🔎 Search functionality (client-side)
🗂 Category filtering system
❤️ Favorites system (localStorage-based)
📱 Responsive design (mobile-friendly UI)
⚡ Fast static performance (GitHub Pages ready)
🧠 Tech Stack
HTML5
CSS3 (custom styling / responsive layout)
Vanilla JavaScript
GitHub Pages (hosting)
